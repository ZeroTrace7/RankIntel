# RankIntel Benchmark Fixtures

This directory contains locked JSON fixtures capturing RankIntel audit results for the **permanent 11-site benchmark suite** (10 industry competitors + Sunrise Testing), configured centrally in [`benchmarks/sites.json`](./sites.json). They serve as regression baselines — tests verify that future code changes do not silently alter scoring behavior.

## Running Regression Tests

```bash
pytest benchmarks/test_regression.py -v
```

No live network required — tests run entirely against [`benchmarks/sites.json`](./sites.json) and the committed JSON fixtures.

## Updating Fixtures

After an **approved** scoring or bug-fix change, re-capture all 11 fixtures or a single site:

```bash
# Re-capture all 11 benchmark sites
python benchmarks/score_snapshot_tool.py --all --confirm

# Re-capture a single site
python benchmarks/score_snapshot_tool.py --site alephindia.in --confirm
```

Then commit the updated fixture file(s) with a descriptive message explaining the change.

> [!IMPORTANT]
> Never manually edit fixture JSON files. They must always be generated by `rankintel audit` via `score_snapshot_tool.py` to be valid regression baselines.
