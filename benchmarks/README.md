## Running Regression Tests

```bash
pytest benchmarks/test_regression.py -v
```

No live network required — tests run entirely against the committed JSON fixtures.

## Updating a Fixture

After an **approved** scoring change, re-capture the affected fixture:

```bash
python benchmarks/score_snapshot_tool.py --site python.org --confirm
```

Then commit the updated fixture file with a descriptive message explaining the change.

> [!IMPORTANT]
> Never manually edit fixture JSON files. They must always be generated by `rankintel audit` to be valid regression baselines.
